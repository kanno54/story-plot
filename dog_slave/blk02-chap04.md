## 第2部第4章「奉仕の深化」──再構成プロット（全5シーン）

**章テーマ**：

> 身体は“使える”ようになった。では、「使い慣れる」には？
> 主・獅堂恭平の判断で、奉仕犬07号は使用人たちの“慰み”として正式に開放される。
> 自分の意思ではなく、主の声ひとつで“誰にでも使わせる”制度の始動。
> 恥辱と支配の位相が変わる。

---

### Scene 1：宣告 ― 使用人への開放命令

* **舞台**：朝、主の部屋。

* **展開**：

  1. 朝の朗唱を終えた隼人に対し、主人は沈黙。
  2. 鐘を鳴らし、腹心の男の使用人を呼び寄せる。
  3. 「こいつ、お前らで使ってやれ。手加減すんなよ？ 」
  4. 腹心の使用人は、承知しました、男衆に相手をさせます、と言って隼人を使用人の控え室に引っ張っていく。

* **心理（隼人）**：

  * 朗唱で得た達成感を、数秒で「晒し者」に引き下ろされる
  * 主に見捨てられたわけではないのに、「主から切り離された」感覚が残る

---

### Scene 2：くちまんこ奉仕

* **舞台**：使用人控えに移送された隼人。胸にくちまんこ開放中と貼り紙をされて放置される。

* **展開**：

  1. 「これがさっき言ってたやつね。使えって指示だからしょうがないよね」と軽い口調でくちまんこを使う
  2. 隼人はくちまんこの口上を述べてから奉仕を行う
  3. かわるがわるにくちまんこを使われる
  4. 開発の成果もあり苦しさよりも使われる悦びに身体を震わせる隼人

* **心理**：

  * 恥語を声にすることで“自分を消す”防衛反応が働きはじめる
  * 声と姿勢に逃げ込むが、身体への反応が濃密になってきて、逃げ場がなくなる

---

### 🟨Scene 3：けつまん奉仕

* **展開**：

  1. 昼食の後も同じ場所に引き立てられた隼人。違うのは姿勢で、四つ這いで背中にけつまん開放中と貼り紙される。
  2. 後ろが見えない状態で待機させられて不安で仕方がない
  3. 尻をピシャリと叩かれてビクっと反応する。直後からけつまんを使われて喘ぐ
  4. 使用人が順番に列をなしてけつまんをひたすら犯される隼人

* **心理**：

  * 誰も命令してないのに、自分から動いてしまっていると気づく瞬間
  * 奉仕が“制度”ではなく、“習性”として定着してきている実感

---

### 🟩Scene 4：主からの夜の言葉

* **舞台**：夜、主に呼び出される
* **展開**：

  1. くちまんこの特化口上⇒指を突っ込み、イチモツもぶちこまれる。主の大きさにむせび泣きながら必死で奉仕
  2. けつまんの特化口上⇒指を突っ込み、イチモツもぶちこまれる。開発済なのに圧倒的な存在感にむせび泣く
  3. 主：「ようやく使えるようになってきたが、まだまだ甘いな。……壊れんなよ？」
  4. 隼人：「ゆるして……んぅ……」

## ✅章トーンと機能まとめ

| 軸       | 内容                             |
| ------- | ------------------------------ |
| 主の承認→開放 | 主に“使える”と認められた上で“他者に供される”構図     |
| 支配の非対面化 | 主が使わず、他者が使うことで“主人の影”が身体に焼きつく   |
| 奉仕の習性化  | 命令がなくても身体が“奉仕動作”を開始する兆候        |
| 恥の耐性形成  | 恥に震える → 恥が消える → 快楽でもない“空白”に堕ちる |
