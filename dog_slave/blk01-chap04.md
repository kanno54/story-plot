# 📘第1部 第4章「部位と名前」

**章テーマ：** 身体を卑語で名づけられ、“恥”として再定義される
**舞台設定：** 訓練室（中央照明・金属製ポール・壁面スクリーン）
**訓練段階：** 「姿勢訓練」→「部位命名」への移行
**目的：** 自分の身体を“恥の構造”として朗唱し、五部位を記憶させる

---

### ◉章概要

隼人の肉体に、初めて“卑語”による名称が与えられる。
「そちん」「けつまん」「ぴんちく」「ぶたばな」「くちまんこ」──それらは笑いと屈辱を伴う命名であり、奉仕犬としての「恥の地図」を完成させるための儀式。
朗唱・姿勢・繰り返しを通して、彼は“恥ずかしい言葉を自分の身体に貼る”ことを強制される。

---

### ◉シーン構成（全5シーン）

#### ●Scene 1：部位命名の宣告

* **概要：** トレーナーが「今日から身体に名前をつける」と告げ、五つの卑語を読み上げる。
* **心理軸：** 驚愕 → 否認 → 無言の反抗。
* **展開：**
  　1. トレーナー：「今日からお前の身体には“奉仕の名”が必要だ」
  　2. 壁のスクリーンに五つの言葉が映し出される。
  　3. 隼人：「ふざけるな……そんな名で呼ばれる筋合いはねぇ！」
  　4. トレーナー：「“そちん”から始めよう」
  　5. 冷たい照明が身体の下半分だけを照らす。
* **象徴要素：** スポットライト＝羞恥の視覚化。

---

#### ●Scene 2：そちん朗唱

* **概要：** 最初に与えられた名、“そちん”。トレーナーが口上を朗読し、隼人に復唱を命じる。
* **心理軸：** 激しい拒否 → 崩壊 → 無理やりの発声。
* **展開：**
  　1. トレーナー：「そちん――人の体にありながら尊さも意味も持たぬ…」
  　2. 隼人：「言えるか、そんなもん！」
  　3. 電子音の警告：「朗唱拒否＝警告」
  　4. 隼人、息を震わせて「……そちん……」と絞り出す。
  　5. トレーナーが冷静に言う：「はい、よくできました。それがあなたの竿の名です」
* **挿入トークン：** 【E7】卑語を自らの部位に貼る羞恥。
* **象徴要素：** 言葉による身体の支配。

---

#### ●Scene 3：けつまん朗唱

* **概要：** 次に与えられるのは“けつまん”の名。基本姿勢で朗唱させられる。
* **心理軸：** 命令に従う自分への嫌悪。
* **展開：**
  　1. トレーナー：「“けつまん”は、お前の後ろの奉仕口だ」
  　2. 四つ這いを命じられ、尻を開かされる。
  　3. 「けつまん――人の体にありながら…」
  　4. 声が震えるが、トレーナーが「続けろ」と促す。
  　5. 「……奉仕犬の隼人にのみ名付けられた恥穴にございます……」
* **挿入トークン：** 【E8】開かされた姿勢で卑語を唱える羞恥。
* **象徴要素：** 開口＝自己の否定。

---

#### ●Scene 4：ぴんちく・ぶたばな・くちまんこ

* **概要：** 上半身と顔の部位に次々と名が与えられる。羞恥が全身を覆い、言葉の意味が消えていく。
* **心理軸：** 自嘲 → 麻痺 → 機械的朗唱。
* **展開：**
  　1. トレーナーがテンポよく読み上げる：「ぴんちく」「ぶたばな」「くちまんこ」
  　2. 隼人は呼吸を乱しながら復唱。
  　3. スピーカーから笑い声が流れる。
  　4. どの言葉にも意味を感じられなくなり、声だけが出る。
  　5. 「……どうぞ、お嗤いくださいませ……」
* **挿入トークン：** 【E9】全身が卑語で塗り潰される麻痺的羞恥。
* **象徴要素：** 言葉の洪水による自我の溶解。

---

#### ●Scene 5：五部位朗唱の完成

* **概要：** 最後に五部位を連続して朗唱する儀式。隼人は自らの口から恥の体系を完成させる。
* **心理軸：** 恥の総括 → 受け入れの始まり。
* **展開：**
  　1. トレーナー：「これが“奉仕犬の身体”の地図だ。順に言え」
  　2. 隼人：「そちん、けつまん、ぴんちく、ぶたばな、くちまんこ……」
  　3. 鏡に映る自分が、その言葉を反響させる。
  　4. トレーナー：「恥を口にできる者だけが奉仕できる」
  　5. 隼人は目を閉じ、ただ声を出し続ける。
* **挿入トークン：** 【E10】恥を体系として受け入れる呪文的朗唱。
* **象徴要素：** 言葉と身体の一致＝“恥の完成形”。
