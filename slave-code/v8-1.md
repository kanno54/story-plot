Slave Code 第一部：二人の例外

改訂章プロット

⸻

部の概要

田所亨は、脱獄済みデバイスを通じて自らSlave Codeを起動した男たちを、ホテルの一室で受け入れ、犬として仕込み、売却する運用者である。

起動済みの男は、到着した時点で身体が命令へ逆らえない。
田所は暴力で相手を制圧しない。
ただ短く命令を置き、拒絶している男自身の身体が、その命令を実行するのを観察する。

田所には「手元に置く犬は0か1」という鉄則がある。

健斗を売却できなかったことで、その鉄則は一度破られる。
二号を売却することで、健斗は主人の犬として他の犬を仕込める存在になる。
轟を売却できなかったことで、田所は二頭の犬を手元へ置く運用へ踏み込む。

第一部は、ホテルの一室から旧体育館のプレイルームへ移るところで終わる。

⸻

第一部共通の禁止事項

* 対象者を取り押さえない
* 殴らない
* 引きずらない
* 格闘、取っ組み合い、暴力的制圧を描かない
* 対象者に逃走や攻撃を成立させない
* 服を力ずくで破いたり剥いだりしない
* 「ステディ」「最古参」という語を使わない
* 犬に田所の固有名を頻繁に呼ばせない
* 商品犬を全員手元に残さない

対象者の抵抗は、内心、台詞、涙、怒り、羞恥、否定、身体の不本意な反応として描く。

第1章：発端

章の目的

田所のホテル運用、条件最適化社会、起動済み対象者の受け入れ方を示す。
健斗をI-01として検収する。

必須場面

* 田所がホテル最上階から、デバイス普及社会を見下ろす
* 田所が健斗のアクセス履歴、身体情報、限界突破への欲望を確認する
* 健斗はすでにSlave Codeを起動しており、自分の足でホテルへ来る
* 部屋へ入った健斗は、理性では不審に思いながらも、田所の「扉を閉めろ」「座れ」に身体が従う
* 田所が、健斗の命令反応を静かに確認する
* 「脱げ」で、健斗は拒絶しながらも自分の手で服を脱ぐ
* 田所が健斗の身体を検分し、首輪とI-01を与える

商品化・官能の焦点

* 裸体を見せる羞恥
* 乳首への最初の反応確認
* 命令と身体の不一致

第一章　発端

この街の連中は、己の意思で靴紐を結ぶことすら放棄した。

窓の外に広がるネオンの海は、効率と最適化の名の下に骨抜きにされた人間たちの排熱だ。タブレットに流れるニュースフィードでは、また新たな『集中力補助』の機能向上が謳われている。人口の八割が口にしているというあのマウスピース型デバイス。ストレス軽減、タイパの向上、行動開始時の心理的摩擦ゼロ。耳障りな言葉で包装されたそれは、要するに「考えなくても生きられる」という免罪符だ。

俺はホテル最上階の窓辺に立ち、夜の街を眺めていた。集中、休息、学習、回復。誰もが自分の状態を管理し、迷いを減らし、摩擦を避けて生きている。合法の範囲で、倫理フィルタの中で。

もちろん、それで済ませない人間はいる。

俺の手元には、タブレットが一枚。開いているのは、今夜の獲物のデータだ。

早川健斗。二十六歳。一時期ボディビルダーとして注目されたが、競技者としては大成せず、三年ほど前から都内のジムでパーソナルトレーナーをしている。客からは体を褒められる。同僚からは指導を頼られる。自分より劣るトレーナーが評価される場面を何度も見てきた。自分の方が強いのに、真面目にやってきたのに、踏み込む勇気がないだけで差をつけられている。その苛立ちが、限界突破への渇望として蓄積されている。

美しいほどに典型的だった。

睡眠を削り、回復効率を上げるパッチから入り、集中維持、反応速度、筋出力の制限解除へと進む。一週間前、ついに倫理フィルタの外れたパッケージに手を出した。欲望は正直だ。もっと強くなりたい、迷いたくない、誰かに評価されたい。

そして昨晩、最終段階としてSlave Codeを起動させた。

データには、起動後の位置情報、身体反応、状態遷移ログがリアルタイムで表示されている。バイタルは安定している。空腹もなく、睡眠も足りている。問題はない。

その身体は、もう俺のものだ。

俺はタブレットを閉じ、ソファへ腰を下ろした。スイートルームの間接照明が、黒い革張りのソファと磨かれた大理石のテーブルを淡く浮かび上がらせている。静かで、清潔で、余計なものは置いていない。

扉をノックする音が聞こえた。予告通りの時間だった。

「入れ」

扉が開く。

早川健斗は、写真よりやや疲れた顔で立っていた。だが背筋は伸びている。黒いTシャツ、膝のあたりが色褪せたジーンズ、スニーカー。ジム帰りのような、街に溶け込む服装だった。

一見すると普通の男が、自分の意思で部屋を訪ねてきた顔をしている。

俺はその目の動きを観察した。瞳孔がわずかに開いている。部屋へ入る前に、何か違和感を感じているのだろうか。だが、足は止まらない。彼は敷居を跨いだ。

「扉を閉めろ」

俺の声は低く短い。健斗は一瞬まばたきをし、何か言いかけたが、右手はもうノブへ伸びていた。ゆっくりと扉が閉まり、ラッチが落ちる。

ここで彼は、初めて自分の身体が聞いたことのない声に従ったことに気づく。眉が寄り、口元が固くなった。

「……あんた、誰だ」

「座れ」

俺は目の前の椅子を指す。健斗の脚はすでに動いていた。疑問を抱きながらも、床を踏みしめ、指定された椅子の前まで歩く。彼は座る。座ってから、自分の膝の上で拳を握る。

「なんで、体が勝手に」

「お前がパッチを入れたからだ。自分で起動したんだろう」

健斗の顔に、初めて明確な恐怖が走った。そうだ、昨夜のあのパッケージ。限界を越えるための最終コード。起動した時、妙にすっきりとした感覚があったこと。その後、このホテルへ向かうよう促されたことを。抵抗しようと思えばできたはずだ。でも、しなかった。いいや、したくなかった。

「俺に何をさせる気だ」

「まずは脱げ」

健斗は立ち上がった。その動きは滑らかで、彼の理性が命令を理解するより早く身体が反応している。彼は自分の手がTシャツの裬をつかむのを見つめた。その手は震えている。顔は青ざめている。唇が「やめろ」と動く。

しかしTシャツは、彼の手によって脱がれた。

露わになった上半身は、予想以上に仕上がっている。ジムで鍛えられた胸は厚く、大胸筋の上部が鎖骨の下で盛り上がっている。肩は丸く、上腕はパンプしていない状態でも太い。腹筋はブロックのように割れており、へその周りには血管がうっすらと浮いている。

雷蔵の目が、見開かれる。一瞬の希望。彼の手がすぐに動き、再びタートルネックを脱ぎ始めた。さっきまで服を着ていた手が、今度は服を脱いでいく。

「出荷用の服はしまえ。お前には不要だ」

「ご主人様……？」

「お前は売らない」

雷蔵の動作が止まった。いや、止まったのは意識のほうで、身体はまだ動いている。最後の靴下を脱ぎ、彼は一糸まとわぬ姿で立ち尽くした。

「俺の犬だ。ここで働け」

雷蔵の膝が、初めて自分から、命令でなく床に落ちた。

「……ご主人様」

巨体が床に手をつき、頭を垂れる。その姿勢には、祈りにも似た重みがあった。

「俺は、使われる犬です。ご主人様の道具になってください」

「道具にはならん。道具に名前はつけん」

俺は雷蔵の顎を持ち上げた。

「お前は轟雷蔵だ。俺のI-03だ。それを忘れるな」

雷蔵の目が、初めて潤んだ。選ばれたことへの感動ではない。使われる場所を、存在意義を与えられたことへの安堵がそこにあった。

俺は後ろを振り返った。

「健斗、こっちへ来い」

健斗が歩み寄り、雷蔵の横に膝をついた。黒いハーネスの一号と、全裸の三号。見事な対比だった。

「並んで跪け」

二人が並び、同時に頭を垂れる。

俺はその光景を眺めながら、腹の奥で湧き上がる感覚を自覚していた。0か1のルールは、もうない。こいつらは例外だ。俺は二頭の犬を手元に置いた。それも、単なる所有欲だけでなく、合理的な判断の結果として。

「悪くない」

俺は呟いた。言葉にした瞬間、それが真実であることが確かめられた。

タブレットを手に取り、バイヤーへキャンセルの通知を送る。ペナルティはない。代わりの商品はすぐに見つかる。

「今日からお前たちは、俺の犬として働く。一号、三号に役割を教えろ。互いの仕事が何かを理解させろ」

「はい、ご主人様」

二人の声が重なった。健斗の声は少しだけ高く、雷蔵の声は地を這うように低い。

俺はソファへ戻り、脚を組んだ。窓の外では、街が夕闇に沈み始めている。このスイートはもう狹すぎる。もっと大きな場所が必要だ。こいつらを自由に動かせる、誰の目も気にしなくていい場所。

俺はタブレットで郊外の不動産情報を開いた。

1. **ホテルの限界** -- 商品犬が増え、設備と管理がホテルの一室で収まらなくなっている現状を田所が認識する。健斗と雷蔵の役割が明確化しつつあるが、スペースが足りない。

2. **短い案件描写** -- I-04が検収され、健斗と雷蔵の補助で商品化される。工程の断片（呼称、脱衣、乳首調律、展示）を簡潔に見せ、商品として売却される流れを示す。

3. **物件決定** -- 田所が郊外の旧体育館を視察し、購入を決める。広さ、プライバシー、改装の自由度を評価する。

4. **プレイルーム改装** -- 主室、中央リング、待機区画、調教区画、司令室、田所の寝室、健斗と雷蔵の居住区画が整備される。

5. **健斗と雷蔵の反応** -- 新しい施設に足を踏み入れた二頭が、それぞれの仕方で喜びと忠誠を示す。健斗は「選ばれたこと」に、雷蔵は「役割が増えること」に反応する。

6. **二頭への宣言** -- 田所が「ここで、俺の犬として働け」と告げる。0か1のルールは終わり、施設運用者としての自覚が生まれる。

8. **第一部の幕引き** -- プレイルームに立つ田所と二頭の犬。第二部への導入として、新たな獲物の影をちらつかせて終わる。

第十章　プレイルーム

三ヶ月が経っていた。

ホテルのスイートは、もはや狹すぎた。クローゼットには商品犬用の衣装と備品が詰め込まれ、バスルームには潤滑剤や洗浄器具が並び、リビングの一角には仮設の待機マットが敷かれている。

I-04が来たのは、つい先週のことだ。二十代後半の元レスラー。肩幅が広く、太い首と分厚い胸板を持つ男だった。健斗が呼称と姿勢を教え、雷蔵が力の要る姿勢保持を補助した。乳首の感度は中程度、後方の受容は良好。四日で仕上げ、昨日バイヤーへ引き渡した。

「I-04、立て。服を着ろ」

俺の命令に、元レスラーは泣きながら出荷用の服を身につけた。売られる恐怖に震えながらも、自分の足で部屋を出ていく。その背中を、健斗と雷蔵が無言で見送った。

扉が閉まると、健斗が俺の足元に跪いた。

「ご主人様。俺は、ここに残れて幸せです」

その声には、安堵と切実さが混ざっている。選ばれたことへの歓喜と、選ばれなかった者たちへの罪悪感。両方が、彼の黒いハーネスに包まれた胸を上下させていた。

雷蔵は違った。直立したまま俺を見つめ、ただ一言だけ言った。

「次の仕事をください」

俺はタブレットを操作しながら、二人の反応の違いを楽しんでいた。

限界は明らかだった。

ホテルの一室では、一度に一頭しか扱えない。待機場所もなければ、調教中に別の犬を隔離するスペースもない。何より、このスイートは俺の生活空間でもある。犬が増えれば、生活は圧迫される。

俺は郊外の物件リストをスクロールした。

旧体育館。バスケットコート二面分の広さ。観客席は撤去済み。更衣室、シャワー室、事務室が付属している。周囲は倉庫街で、夜間の人通りはない。プライバシーは完璧だ。

その日のうちに内見を済ませ、俺は購入を決めた。

改装は三週間で完了した。

メインの空間である「主室」。元バスケットコートの広さを活かし、中央には低いリング状の展示台を設置した。床は滑りにくい黒いマットで覆い、壁面には間接照明が埋め込まれている。犬たちがどこに立っても、その身体が光と影で強調されるように計算されていた。

主室の奥には「調教区画」。防音壁で仕切られ、調教台、洗浄設備、姿勢保持のためのバーが設置されている。隣接して「司令室」。全面ガラス張りで、主室と調教区画の両方を見渡せる。タブレットやモニター、通信機器が並び、ここで俺は犬たちを管理する。

主室の反対側には「待機区画」。商品化前の犬を一時的に留め置くための個室が四つ。それぞれに最低限の寝台と衛生設備がある。完成した商品犬は、別の「納品前待機室」で出荷を待つ。

そして、俺の「寝室」。司令室の奥にある、完全にプライベートな空間だ。キングサイズのベッド、ウォークインクローゼット、シャワー室が備わっている。

さらに、寝室の隣には「居住区画」を設けた。二頭分の寝台、収納、小さなシャワー室。俺の手元に残る犬のための専用スペースだ。

完成したプレイルームに、俺は最初に健斗と雷蔵を連れて入った。

広大な主室を見渡し、健斗が息を呑む。

「ご主人様……ここは……」

「俺たちの城だ」

俺は言った。健斗が俺の足元に跪く。何も命じていない。自らの意思で膝をつき、俺の革靴に口づけた。

「選んでくださって、ありがとうございます……」

その声は震えている。健斗の目から涙がこぼれ、革靴の表面を濡らした。俺は彼の頭に手を置いた。

「健斗」

「はい」

「お前は俺の最初の犬だ。これからも変わらん」

健斗は俺の手の下で、声を押し殺して泣いた。

雷蔵は違った。彼は主室をゆっくりと見渡し、リング、調教区画のバー、司令室のガラスを順に確認してから、一歩前に出た。

「ご主人様、力仕事なら任せてください。荷物の運搬、設備の維持、それから……」

言葉を切り、少しだけ迷ってから言った。

「言え」

「はい。従わない犬がいたら、俺が支えます。力を貸してください」

ちがう、と雷蔵は言い直した。

「力をお使いください。ご主人様」

俺は雷蔵の肩を叩いた。岩のように硬い筋肉が、俺の手のひらの下で熱を持っている。

「任せる」

それだけで、雷蔵の顔に静かな充実が広がった。

俺は腕時計を見た。午後九時。

「今日はここまでだ。居住区画に行け。お前たちの場所だ」

二頭を居住区画へ向かわせ、俺は司令室に入った。革張りのチェアに腰掛け、モニターの電源を入れる。

タブレットに通知が表示された。新しいアクセスログ。誰かが限界突破パッチを起動し、Slave Codeが作動し始めている。I-05だ。到着予定は四十八時間後。

かつて俺は、0か1のルールに縛られていた。手元に置く犬は常に一頭。それ以上は商品。情を持ち込まないという鉄則。

だが今、俺の足元には二頭の犬がいる。郊外の旧体育館を改装した施設まである。俺はもう、ホテルで一人だけの運用者ではない。

モニターには、主室の中央リングが映っている。空っぽの照明が、次の獲物を待っていた。健斗と雷蔵の気配が、すぐ後ろの居住区画からかすかに聞こえる。二頭の犬。二つの例外。

俺はタブレットを手に取り、I-05のプロファイルを開いた。新しい獲物が、すでに近づいている。

「悪くない」

俺は呟いた。その声は、誰もいない司令室に吸い込まれていった。だが、すぐ後ろで二頭の犬が俺の言葉を待っている。その事実が、かつてない充足感を俺に与えていた。

ここが、俺の場所だ。

**第二部への接続について**

第二部は、このプレイルームでI-05を迎え入れる場面から始めることになります。健斗と雷蔵という二頭の犬を擁し、専用施設で運用を行う田所の姿が、新たな物語の起点です。

必要であれば、第二部の執筆基準やプロットの設計も承ります。
