・回収依頼（バカな脱獄ユーザー）が多すぎて主人公一人の身体ではキャパオーバーになり、主人公は調教済みの健斗（1号）を相棒（助手）に引き上げる。

### 第5章：交錯（ミックス）──蓮（れん）と大河（たいが）の変則調教

### 第6章：崩壊（キャスティング）──嶋田（しまだ）の分解と狂乱の宴
・【ターゲット：嶋田（185cm/90kg、現役の特殊部隊員・特殊作戦群。本物の殺人マシン。のちのイヌ16号）】

・【狂乱の宴】：イヌの数はついに20人を超え、部屋中に肉と肉がぶつかる音と男たちの嬌声が響き渡るなか、20人の巨漢たちが互いの身体を貪り合い、主人公の逸物を奪い合う、支配の極致たる大乱交へと発展する。
### 第7章：反転（ループ）──終わらない最適化 ※結末
・調教を終え、第4調教室（司令室）での情事のあと、健斗（1号）が主人公の胸に顔を埋めながら「先輩、この回収の仕事って、本当は誰に頼まれてるんですか？」と純粋な疑問を口にする。

・矛盾が臨界点を超えた瞬間、耳の奥で冷たいシステム音《思考リミッター作動。バッファをクリアします》が鳴り、意識が強制的に暗転。
・次の瞬間、主人公は「夜の高速道路を走る車の中（助手席）」で目覚める。司令室にいたはずの記憶や、時間跳びの違和感、恐怖は、デバイスのパニック抑制機構（快感）で綺麗にデフラグ（消去）されている。
・隣で運転する健斗（1号）のスマホに新たな獲物の通知が鳴り響き、主人公は何の疑問も抱かず、口角を吊り上げて自分のマウスピースを【ガチリ】と深く噛み締める。彼自身が、巨大なシステムに一番都合よく飼われている「最上位の奴隷」であることに気づかぬまま、終わらない最適化の日常へとループしていく。

# 第1章：発端（オリジン）

深夜の高速道路を走る車内で、俺はスマートフォンの画面を漫然とスクロールしていた。

タイムラインには、いつもと同じ「最適化」の文字が溢れている。睡眠の質を最適化。食事の栄養バランスを最適化。集中力の波形を最適化。どれもこれも、人間を機械の部品のように扱う言葉たちだ。だが、そんな常識は、この社会ではもう通じない。

誰もが「最適化」を求めている。誰もが「効率」を追い求めている。誰もが「摩擦ゼロ」の快適さに慣れきっている。歯の裏に貼り付けた透明なマウスピース型デバイスが、起床から就寝まで、あらゆる行動の「面倒くさい」を取り除いてくれるのだ。

便利だ。快適だ。何も考えなくていい。

公式には「集中力補助」「ストレス軽減」と説明されているこのデバイスは、今や人口の八割が装着している社会インフラだった。学校も、職場も、スポーツジムも、デバイスを前提としたプログラムしか組まなくなっている。

そして誰もが「もっと効率を上げたい」と思っている。少しでも楽に、少しでも早く、少しでも無駄なく。その「少し」を埋めるために、人間は疑うことをやめる。安全フィルタを外すことを怖がらなくなる。

だから俺の仕事は、なくならない。

画面をタップし、専用の管理パネルを開く。そこには地図アプリと見分けのつかないインターフェースで、今日「回収」すべきターゲットの位置情報が表示されていた。

《未承認コード検出：3件》
《優先度：高》
《推定リスク：低〜中》

ふん、と鼻を鳴らす。今日もまた、自分の脳みそを無法地帯に改造したバカが三人もいるらしい。トレーニング効率を上げたいだの、試験勉強を楽にしたいだの、そんな甘い考えで脱獄コードを突っ込んだ連中だ。

彼らは知らない。その「便利なパッチ」が、誰かにとっての「首輪」になりうることを。

俺は自分のマウスピースを舌でなぞった。奥歯で噛み締めれば、それはただの生活補助デバイスから、まったく別のものに変わる。この歯の裏にある小さな機械が、どれほどの力を持っているか----知っているのは、俺と、俺の「犬」たちだけだ。

最初のターゲットのプロフィールを開く。

名前：篠崎健斗（しのざき・けんと）。年齢24歳。身長182センチ、体重80キロ。職業はパーソナルトレーナーで、インストールした脱獄コードは「筋出力最適化パッチ Ver.3.2」。説明文には「意識的な筋制御のタイムラグをゼロに。トレーニング効率300%向上」とあった。

「バカかよ」

俺は笑った。タイムラグをゼロに----つまり、脳が筋肉に指令を出すプロセスを、まるごとデバイスに明け渡すということだ。自分の肉体を、自分の意志で動かす権利を、何の疑問もなく手放している。

場所は都内のビジネスホテル。どうやら彼は今夜、そこで新しい「パフォーマンス」を試すつもりらしい。俺はハンドルを切り、高速を降りた。


ホテルの一室。チェックインから三十分後、健斗はスウェット姿でベッドに腰掛け、自分のスマホを眺めていた。画面には「インストール完了」の通知。

「これで明日のレッグデイが楽しみだな」

彼は呟き、自分の大腿筋をポンと叩いた。競技ボディビルを引退して三年。今はジムで客を指導する立場だが、自分の身体も常に完成形に近づけたい。そのためには、合法的な範囲での「サポート」は当然の選択だった。

誰だってやってる。プロテインを飲むのと同じだ。彼はそう自分に言い聞かせた。

ふと、ノックの音が響く。ルームサービスの時間には早すぎる。健斗は眉をひそめ、ドアスコープを覗いた。そこに立っていたのは、スーツ姿の若い男----俺だった。

「どちらさまでしょうか」

「デバイス管理センターの者です。お使いのデバイスに深刻な異常を検知しました。緊急の安全確認をお願いします」

健斗は迷った。デバイス管理センター。そんな機関から直接来るなんて聞いたことがない。しかし、「深刻な異常」という言葉が、彼の不安を刺激する。たった今インストールしたパッチのことが頭をよぎった。

----まさか、バレるはずがない。

「お部屋までお伺いしたのは、外部への漏洩を防ぐためです。どうかご協力を」

俺の声は落ち着いていて、しかし有無を言わせない響きがあった。

健斗はドアを開けた。


部屋に入ると同時に、俺はドアを閉めてチェーンをかけた。健斗が「あの、異常って----」と言いかけた瞬間、俺の指が彼の額に触れる。そこには貼り付け型の小型デバイスが仕込まれていた。

「な----っ」

言葉が途切れる。彼の身体から力が抜け、膝が折れた。完全な意識消失ではない。筋肉の随意制御だけが、一時的にブロックされる。

「安心しろ、麻痺は数十秒で切れる。その間に説明する」

俺は彼の顎を持ち上げ、口の中を確認した。予想通り、上顎の奥に透明なマウスピースが装着されている。

「お前が入れたパッチ----『筋出力最適化』ってやつ、あれは脱獄コードの中でも特に危険な部類だ。筋肉への命令係統をデバイスに委譲するってことは、裏を返せば、デバイスを掌握した人間がお前の身体を思いのままにできるってことだ」

健斗の目が恐怖に見開かれる。指先がかすかに痙攣し始めていた。麻痺が切れかけている。

「なぜ……お前に……」

「俺が管理者だからだ。お前たちみたいなバカを掃除するのが仕事でな」

俺は彼の口の中に手を入れ、マウスピースに細工を施した。これで、彼のデバイスは俺の送信機とペアリングされる。

「さあ、時間だ。服を脱げ」

「ふざけるなっ！」

麻痺から完全に回復した健斗が、俺を突き飛ばそうと腕を伸ばす。182センチの鍛え上げられた身体は、見た目通りのパワーを持っていた。だが----。

「ガチリ」

俺が奥歯を噛み締める音が、部屋に小さく響いた。

とたんに、健斗の動きが止まる。いや、正確には、彼の「意志」が止まったのだ。伸ばされた腕は目標を失い、だらりと下がる。彼の顔にはまだ怒りと混乱が浮かんでいるのに、身体だけが靜かにベッドの横に立っていた。

「なにを……なにをした……！」

声は震えていた。だが、指先はすでに、自分からスウェットの裾を掴んでいる。

「お前の脳が『服を脱げ』という命令を拒否した。だから、その拒否反応を俺が消しただけだ。デバイスの基本機能----行動開始時の心理的摩擦をゼロにする。それをちょっと応用しただけさ」

鍛え抜かれた身体だった。胸板は厚く、大胸筋の上部と下部が明確に分離している。腹直筋は六つに割れ、斜腹筋がサイドを引き締めている。大腿四頭筋は丸太のように太く、ふくらはぎはダイヤモンド型に尖っていた。何年もかけて作り上げた、完璧なスポーツマンの肉体。

「いい身体だな。大事にしてきたんだろう」

答えない健斗の目から、涙が一筋こぼれた。彼の意志はまだ抵抗を続けている。唇を噛みしめ、眉を歪め、なんとか身体の主導権を取り戻そうとしている。

だが、それも無駄だ。

「四つん這いになれ」

「やめ……やめてくれ……」

「四つん這いになれ」

「お願いだ……頼む……！」

「四つん這いになれ」

三度目の命令で、健斗の身体は滑らかに動き出した。まるで生まれたときからそうするように定められていたかのように、彼は両膝と両手をカーペットにつき、顔を上げて俺を見上げる姿勢をとった。その動きは優雅ですらあった。

「どうして……どうして身体が……！」

彼の声は涙で濡れていた。頭は拒絶しているのに、肉体は完全に俺の命令に従っている。その矛盾が彼の精神を苛み、深い混乱を生み出している。

俺はしゃがみ込み、彼の顔をのぞき込んだ。

「よく見ろ、健斗。お前の身体は、お前の意志より、俺の命令を優先している。これはもう、お前の身体じゃない。俺の身体だ」

「違わない。証拠を見せてやる」

俺は指一本触れなかった。ただ、彼の耳元で囁くように言った。

健斗の全身が硬直した。

彼の腰がひとりでに突き出され、カーペットの上で何も触れていないペニスが、激しく脈打った。先端から透明な液が溢れ、やがて白濁した精液が飛び散る。彼は一度も自分に触れていない。触れられてもいない。それなのに、身体だけが命令に応えて射精したのだ。
