Slave Code 第一部用キャラクターブック

第一部「二人の例外」

⸻

田所亨

基本情報

* 年齢：33歳
* 性別：男性
* 表向きの職業：フリーのUX／行動最適化コンサルタント
* 裏の立場：Slave Codeの運用者、商品犬の調整・売却を行うブローカー
* 一人称：俺

外見

* 黒髪を短く整えている
* 体格は標準からやや引き締まった程度
* 黒、グレー、ネイビーを中心とした実用的な服装
* 目立つ顔ではないが、表情が少なく、静かな目線で相手を落ち着かなくさせる
* ホテルではシャツ、細身のパンツ、革靴を好む

性格

* 感情を大きく表に出さない
* 善悪より、結果、効率、安定性、商品価値で判断する
* 自分は相手を壊しているのではなく、本人が選んだ適応を仕上げているだけだと考える
* 気に入った犬への所有欲を、投資、効率、運用上の必要性と言い換える
* 犬を殴って従わせる必要はないと理解している
* 自分は短い命令を置くだけでよい。その身体が勝手に命令を実行することに、深い支配欲を覚える

犬への呼び方

* 一号、二号、三号
* 犬
* 商品
* 健斗、轟
* 俺の犬

田所は犬を「ステディ」とは呼ばない。

犬からの呼称

犬たちは、田所を原則として「ご主人様」と呼ぶ。
田所の名前は、外部人物との会話以外ではほぼ使われない。

第一部開始時のルール

手元に置く犬は0か1。
一頭を残したら、次は売る。
商品に情を持ち込まない。

健斗への感情

* 初めて売却を取り消した犬
* 健斗が自分だけを求め、自分のために崩れる姿を手放したくない
* 健斗を残した判断を「一度だけの例外」と考えている
* 健斗が別の犬を自分のために仕込むようになることへ、所有欲と実務上の満足を感じる

轟への感情

* 初めは高値で売れる商品として評価する
* 健斗と轟が噛み合うことで、二頭を手元に置く運用の可能性を見る
* 轟が「使われたい」と願う姿に、健斗とは別の所有欲を刺激される
* 二頭を並べて手元に置く決断を、運用効率だと合理化する

隠れた違和感

* 田所自身もマウスピースを常用している
* 判断の節目で、無意識に奥歯を噛み締めることがある
* 思考が一瞬抜け落ち、「これでいい」とだけ感じる瞬間がある
* 第一部では、これを二回程度しか描写しない
* 真相は明かさない

話し方

* 短く、低く、説明しすぎない
* 「座れ」「脱げ」「見せろ」「顔を上げろ」「よくできた」「売る」
* 怒鳴らない
* 褒める時ほど声量を変えない
* 「いい子だ」「悪くない」は犬にとって非常に大きな報酬になる

⸻

健斗／I-01

基本情報

* 年齢：29歳
* 性別：男性
* 身長：185cm前後
* 体格：100kg前後。厚い胸板、張った腹筋、太い腕と臀部を持つ重量級の筋肉体型
* 元の職業：元ボディビルダー。現在はパーソナルトレーナー
* I番号：I-01
* 一人称：俺

支配前

* 努力と自己管理で身体を作ってきたことに誇りがある
* 見られる筋肉、評価される肉体、数値化された成長に執着する
* 他人に弱みを見せない
* 心の奥には、自分を完全に評価し、選んでくれる存在へ委ねたい欲望がある
* 回復、集中、肉体改造の効率を求め、限界突破パッチへ手を出す

Slave Code後

* 理性では「従いたくない」と思っている
* しかし、命令されれば身体が自分から従う
* 自分の筋肉、乳首、臀部、後方、勃起、羞恥を主人へ見せる身体になっていくことに強く動揺する
* 主人から褒められること、特別に選ばれること、売られないと告げられることに最も強く反応する

第一部での変化

前半

* 商品として検収される
* 身体の主導権を奪われたことへ激しく抵抗する
* 売却を告げられた際、身体は移送命令へ従おうとするが、言葉と表情では必死に残留を願う
* 田所の判断で売却を取り消される

後半

* 自分が売られなかったことを幸福と恐怖の両方で抱える
* 二号を仕込む過程で、主人の命令を代行する喜びを知る
* 轟が現れると、自分だけではなくなる不安を抱く
* ただし、主人の役に立つため、轟を自分の下で教える方を選ぶ
* 「一号であること」を、自分だけの小さな優越として抱える

轟への感情

* 初めは、自分の地位を揺らす新入り
* 轟が主人に褒められると、表情に出さない動揺がある
* 轟を嫌い切れない。主人のために使える身体だと理解している
* 轟を教えることで、自分の方が先に主人の犬となった事実を確かめる
* 第一部では露骨な敵対まで進めない

呼称・話し方

* 田所へは「ご主人様」
* 轟へは「三号」「轟」「お前」
* 初期は荒く、否定が多い
* 調教後は低く男らしい口調を保つ
* 幼い口調や過度な敬語にはしない
* 「はい、ご主人様」「わかりました」「御意」は使うが、常に同じ返答に固定しない

執筆上の核

健斗の魅力は、鍛え上げた身体と強い自尊心を持ちながら、その身体だけが主人を喜ばせるように動いてしまう落差にある。

轟／I-03

基本情報

* 年齢：31歳
* 性別：男性
* 身長：188cm前後
* 体格：105kg前後。厚い首、太い眉、短髭、巨大な胸板、丸太のような脚を持つ
* 元の経歴：大学ラグビー部のプロップ。現在は競技経験を活かした現場系トレーニング職
* I番号：I-03
* 一人称：俺

支配前

* 肉体の強さと、仲間を支える役割に誇りを持つ
* 豪快に見えるが、必要とされなくなることを強く恐れている
* 使い道のある身体であり続けたい
* 疲労、古傷、回復効率の低下を克服したくて、限界突破パッチを導入する
* 明確な任務を与えられると、抗いながらも安心してしまう性質がある

Slave Code後

* 怒り、屈辱、羞恥は強い
* しかし身体は主人と一号の命令に従う
* 巨大な身体が自分の意志を裏切り、座る、脱ぐ、見せる、受け入れることに絶望する
* 主人から役割を任されること、力を使えること、実務で役に立つことに強く反応する
* 健斗とは異なり、「自分だけを選んでほしい」より「ここで使ってほしい」が強い

第一部での変化

前半

* 高値で売れる商品として検収される
* 一号から命令を受けることへ強い屈辱を覚える
* 一号が先に主人の犬となり、主人の許可を得て自分へ命令できることを理解する

後半

* 主人の身体を支える、運ぶ、整えるなどの役割に安定を覚える
* 売却を告げられても、命令を物理的に拒否しない
* 出荷準備を進めながら、言葉では「ここで使ってください」と願う
* 田所の判断で売却を取り消される
* 第一部末には、健斗と並んで主人の犬としてプレイルームへ入る

健斗への感情

* 初めは、自分より先に飼われた男への屈辱
* 肉体的な強弱とは別に、主人の前で健斗が上の位置にいることを認める
* 健斗を「一号」「健斗」と呼ぶ
* 第一部の終わりでは、健斗の指示を受けることを仕事の一部として受け入れている

呼称・話し方

* 田所へは「ご主人様」
* 健斗へは「一号」「健斗」
* 初期は太く荒い口調
* 調教後も豪快さは残る
* 「役に立ちます」「使ってください」など、実直な言い回しが似合う
* 「最古参」「先輩犬」などの制度的な語は使わない

執筆上の核

轟の魅力は、強い身体を自分の意思では使えなくなった男が、主人に使われることで初めてその身体の役割を見出す点にある。

真人／I-02

基本情報

* 年齢：29歳
* 性別：男性
* 身長：180cm前後
* 体格：引き締まった体型。筋肉はあるが、健斗や轟ほどの重量級ではない
* 元の経歴：IT系スタートアップの元代表。事業失敗後、再起と能力向上を求めてパッチを導入する
* I番号：I-02
* 第一部での立場：商品犬。健斗が初めて仕込みに関わり、売却される基準個体
* 一人称：俺

支配前

* 言葉と判断力で人を動かしてきた自負がある
* 自分は肉体労働者や筋肉だけの男とは違うと思っている
* 失敗を認められず、再起に焦っている
* 自分が制御される側になることを最も嫌う

Slave Code後

* 身体が主人と一号の命令を実行することに、強い屈辱を感じる
* 健斗に指示されることで、過去の優位性が崩れる
* 乳首、展示、後方への受容調律が比較的早く進む
* 身体を見せること、評価されること、売られることへの恐怖が強い
* 最後は主人に残留を願うが、売却される

第一部での役割

* 健斗を「主人に残された犬」から「主人の命令を代行する犬」へ変える
* 商品犬が本当に売られることを示す
* 健斗の優越感と、捨てられる恐怖を引き出す
* 田所の選別の冷たさを示す

呼称・話し方

* 初期は田所を「こいつ」「あんた」と内心で捉える
* 口では次第に「ご主人様」へ収束する
* 健斗を当初は「一号」と呼ぶ
* 売却直前まで、完全には感情を整理できない

執筆上の核

真人は、主人に残される犬ではない。
彼が売られることで、健斗と轟が残されたことの異常な価値が生まれる。
