# 第1章 不器用な男

競技場に重い静寂が落ちていた。

係員たちが冬木のぐったりした身体を台車に乗せ、暗がりへと運び去っていく。床には、冬木が最後に漏らした先走りの水溜りと、汗の染みがまだ生々しく残っている。それらは冷たい照明の下で濡れた光を放ち、かつてそこに一人の男が崩れ落ちたことを無言で主張していた。

田中は、その光景を目で追った。冬木はもう戻ってこない。CCH躯畜房。番号と属性で管理される身体資源としての世界。一度落ちれば、市民としての冬木将人は消滅する。

自分が落としたのだ。
自分の尻に冬木を咥えこみ、狩野の手に腰を引き下ろされ、その硬さを内壁の奥まで擦り上げて、弾けさせた。

田中は、自らの股間と尻の奥に残る熱を意識せずにはいられなかった。
下半身は、まだ濡れていた。冬木が自分の中に放った白濁が、腸壁からゆっくりと溢れ出し、内腿を伝って太ももの内側を濡らしている。窄まりは、狩野に反復された開閉と、冬木の侵入によって完全に形を崩し、ヒクヒクと空気に触れては收縮を繰り返していた。閉じきらない。まだ異物を求めているかのように、赤く熟れた粘膜が卑猥に口を開けたままだ。

股間の前も、冬木を責めるために勃ち上がっていた陰茎が、先走りを垂れ流しながらまだ半勃ちの状態で重く揺らいでいる。身体の芯に、あの狩野の手の感触と、冬木の熱がこびりついて離れない。

「……」

田中は、競技場の最奥に置かれた玉座へと歩み寄った。
冬木が座っていた場所。冷酷な調教師として君臨していた場所。今は、自分が座るべき場所だ。

硬い肘掛けに手を置き、冷たい座面へと腰を下ろす。
その瞬間、尻の肉が圧迫され、まだ腫れた窄まりがシートに押し潰される感覚に、田中は短く息を詰まらせた。

「んっ……」

反射的に漏れた甘い吐息。尻の奥がズクリと疼く。

早く立ち上がりたかった。しかし、それはKINGの座り方ではない。田中は太ももの筋肉に力を込め、その刺激を噛み殺して深く腰を沈めた。

これは競技だ。
合理的な手順の結果だ。冬木を落とすために、自分の身体を使った。それだけのことだ。

競技なのに。合理的に進めなきゃいけないのに。

田中は震える声で言った。
それはKINGとしての命令ではなく、ただの男としての頼みだった。この身体の疼きを、どうにかしてくれる相手へ向けた、卑屈で、しかし正直な懇願。

不器用な王と、唯一の奴隷。
残された二人の、行き場のない欲望のぶつかり合いが、今、始まろうとしていた。

# 第2章 トレース

冬木が放った白濁は、腸壁から溢れ出し、内腿をねっとりと伝い、シートの上に淫らな水溜りを作りつつあった。窄まりは未だにヒクヒクと収縮を繰り返し、閉じきれない粘膜が冷たい空気に晒されて甘く疼く。

# 第3章 正しいだけの王

田中は、パドルを握る手に力を込めた。隠さない。自分がどうしたいか、もう誤魔化さない。
田中は、狩野の前に立った。
一方の手で狩野の太い首根っこを掴み、無理やり顔を上げさせる。
もう一方の手で、パドルを振り上げた。

「んっ……！」

狩野が短く息を呑む。

ズシリとした手応え。掌に伝わる反動と共に、狩野の太い身体がガクンと揺さぶられる。

「ぐっ……！ うぅっ……！」

狩野は歯を食い縛り、呻き声を殺した。
尻に走った衝撃は、皮膚の表面を焼くような熱さと、筋肉の奥底まで響く鈍痛の二重奏だ。打たれた部位が瞬く間に白から赤へと変色していくのが、田中の目にも見て取れた。
だが、田中は手を休めない。

バシッ！ バシッ！ バシッ！

容赦ない連打。
右の肉、左の肉、座面の真下。
部位を変え、角度を変え、重さを変えながら、田中はパドルを振り抜き続けた。
振り下ろすたびに、狩野の身体が跳ねる。
筋肉の塊のような尻が、打撃のたびに波打ち、赤黒く熟れ上がっていく。
その視覚的な変化が、田中の嗜虐心をさらに煽る。

「あぁっ……！ くそっ……！ ぐぅっ……！」

狩野の口から、耐えきれない唸り声が漏れ始める。
だが、その顔はもはや苦痛だけに歪んでいなかった。
打たれる瞬間に強張る表情。衝撃が走った直後の脱力。そして、次の一撃を待つ時の、切迫した緊張。
それらが交差する表情の変化の速度。
痛みと、その向こうにある微かな熱。それらがない交ぜになった顔が、田中の目の前で激しく明滅している。

綺麗だ。と、田中は直感した。卑猥な意味での綺麗さではない。生身の男が、痛みに耐え、それでも自分を見つめ返してくる、生々しい存在の輝き。

冬木の、あの静謐な支配の顔とも違う。機械に嬲られるだけの肉の顔とも違う。これは、俺が叩き出した顔だ。俺が、この男の痛みと快楽を管理している証だ。

田中は、パドルを振り上げたまま動きを止めた。寸止めだ。

次の一撃が来ると思い込んで身を強張らせた狩野の表情が、来ないことに気づいて戸惑い、そして安堵と次への期待がない交ぜになった表情へと変わっていく。

「狩野さん」

田中は、首根っこを掴んでいた手を離さず、さらに強く握り込んだ。
男の喉仏が圧迫され、呼吸が浅くなる。
「俺が見たかったのは、その顔です」

田中は、自分の声が震えていないことに驚いた。
興奮しているはずなのに、声だけは静かで、芯が通っていた。
「痛みに歪んで、それでも俺を見てる。その顔を見ていたくて、俺はこれを振るってる」

告白だった。
支配者としての余裕でも、虐待者としての狂気でもない。
ただ、目の前の男の表情に執着する一人の人間としての、身勝手な告白。

狩野は、潤んだ目で田中を見上げた。
首を締められ、顔を赤くし、尻はパドルで叩かれて熟れ上がっている。
男としての尊厳など、残っていないはずだ。
なのに、田中の言葉は、その残骸のような自分に向けて放たれている。
俺を見ている、と。

ただのサディストじゃない。
この男は、俺の痛みと、俺の目を、全部欲しがっている。

「だったら」

赤く腫れた唇が、挑むように歪む。
「最後まで見ろ」

物凄い台詞だった。
負けるかもしれない。躯畜房に落ちるかもしれない。それでも、てめぇが俺を見るなら、俺は最後までその目に映ってやる。

バシィッ！！

再び、パドルが唸りを上げて振り下ろされた。
今までで最も重く、最も深い一撃。
