# 2. KING-LAST現行ルールの要点

KINGは毎ターンランダム交代しない。
一度KINGになると、失脚するまで王権を保持する。

KINGは1ターンに1枚の命令カードを切る。
カード条件内で、主対象と補助役を指定できる。
主対象には、そのターンの主要な調教履歴が刻まれる。
補助役にも履歴は残るが、中心は主対象である。

通常カードは履歴を積む手続きである。
CUMSHOT TRYは、通常カードで積んだ履歴によって対象がDROP段階まで完成しているかを判定する、制度上の正式な射精判定である。
通常カードの延長として単に刺激を強めるだけではない。

射精した参加者は、どの局面でも即時DROPする。
TRY中だけではなく、通常カード中、ミラー中、補助役中でも射精すればDROPである。

KINGがCUMSHOT TRYに失敗した場合、TRYを耐えた主対象がCROWN BREAKERとなり、次代KINGになる。
失脚したKINGはDEBTとなり、自分が在任中に行った命令履歴を正順で返される。
これがミラー・カスケードである。
ミラーは逆順ではなく正順。

第二部の主題は「反応が出たことと、完成したことは違う」である。

冬木は田中の反応を正しく拾う。

田中には効かなかった台帳が、ミラーで冬木に返ると本当に効く。
冬木は、田中を見ていたつもりで、最後には自分自身を投影していたことを暴かれる。

# 5. 田中達也の描写制御

田中は無反応ではない。
恥じらいはある。
身体も反応する。
声も詰まる。
ただし、外へ派手に崩れすぎない。

第一部からの基本は「反応は外へ派手に出ない」「耐えるほど内側へ蓄積する受容反応」である。
第3校では、田中を毎章泣き叫ばせたり、毎章限界寸前にしない。

田中の反応は、主に以下で描く。

* 呼吸が浅くなる
* 肩や背中や太腿の筋肉が硬くなる
* 声が詰まる、短くなる
* 顔を伏せる
* 視線を逸らす
* 姿勢を崩さず保とうとする
* 身体だけが刺激へ寄る
* 終了後に、異様に早く整う
* 「大丈夫です」「続けられます」「俺が引き受けます」で処理しようとする

田中を「CCHで完成済みの商品個体」として描かない。
田中は再統合支援施設で高負荷案件へ過適応した男である。
顧客対応、代役、奉仕役、受容姿勢、見られる状況への反射はあるが、KING-LASTの正式履歴は第一部から積まれている。

田中の怖さは、強く反応した後にすぐ整うことにある。
「次は何をすればいいですか」は重要だが、毎章同じ形で繰り返しすぎない。
使うなら、章の決め所に限定する。

# 6. 冬木将人の描写制御

冬木は市川より有能である。
冬木は派手な煽りで観客を盛り上げる王ではなく、条件を絞り、反復し、履歴を積む王である。

冬木は以下を重視する。

* 姿勢
* 呼吸
* 視線
* 役割
* 反復
* 恥
* 自己認識
* 停止位置
* 同じ相手による再現性

冬木の台詞は、下品な煽りや所有欲の叫びに寄せすぎない。
市川のような配信者的な口調にしない。

冬木の命令は、短く、冷静で、手順型にする。

例：

* 「狩野を固定する」
* 「同じ条件で積む」
* 「田中、報告しろ」
* 「今の反応を残す」
* 「止めろ。そこが次の開始点だ」
* 「反応は出ている。まだ完成していない」

冬木を無能にしない。
冬木の分析はかなり正しい。
失敗は、田中の恥じらいと受容反応を、田中自身の欲望と誤読した一点にある。

# 8. 第二部の流れ

## 前半：尻拡張フェーズ

冬木は田中を「尻で崩れる男」と読む。
狩野を実行役として固定する。
前半では田中の尻を段階的に拡張する。

流れは以下。

1. 狩野の指による初期拡張
2. 指の本数・保持時間を増やす
3. 小型器具で保持拡張
4. 段階式器具で拡張幅を上げる
5. 拡張状態で狩野へ奉仕させる

前半の目的は、田中に「狩野に開かれる身体」の履歴を積むこと。
ただし田中は、それを自分の欲望として受け取らない。
命令として処理する。

## 後半：狩野による挿入反復フェーズ

後半では、拡張された田中を狩野に受けさせる。

流れは以下。

6. 狩野による初回挿入
7. 狩野による反復挿入、停止と再開
8. 犯されながら自己申告
9. 総仕上げ
10. CUMSHOT TRY

後半の目的は、田中に「狩野が来る」「狩野を受ける」「狩野を待つ」履歴を積むこと。
冬木には、田中が狩野を待っているように見える。
実際には、田中は次の手順に備えているだけである。

「俺が引き受けます」は、田中にとって欲望の言葉ではない。
自分が受ければ場が収まるという、自己犠牲と処理の言葉である。
冬木はこれを屈服と誤読する。
狩野はこの言葉に違和感を持つが、まだ完全には言語化しない。

## TRY失敗

冬木は、第10ターンで田中へCUMSHOT TRYを行う。
田中の身体は反応している。
恥じらいもある。
観客にも冬木にも、落ちる寸前に見える。

しかし田中はDROPしない。
快感や羞恥を、自分の欲望として奥まで受け取れないからである。

TRY失敗。
田中がCROWN BREAKERとなり、冬木はDEBTへ落ちる。

## 冬木ミラー

冬木には、自分が田中へ行った命令履歴が正順で返る。
狩野が実行役となり、冬木が受ける。

返済は以下。

* 指による拡張
* 保持時間増加
* 小型器具
* 段階式拡張
* 拡張状態での奉仕
* 狩野による初回挿入
* 反復挿入
* 犯されながら自己申告
* 総仕上げ

田中には処理だったものが、冬木には本当に効く。
冬木は、自分で組んだ台帳に自分で落ちていく。

## 田中の追撃カード

ミラー終了後、冬木はまだDROPしていないが限界に近い。
田中はKINGとして、冬木を主対象にした追撃カードを切る。

カード内容は、口唇奉仕と尻奉仕。
通常カードでは手による陰茎への直接刺激は禁止。
口唇奉仕と尻奉仕は、カードが明示的に許可する場合のみ合法。
第3校では、手で直接扱く描写を入れない。

冬木は通常カード中に射精し、即時DROPする。
これはTRY成功ではなく、通常カード中の射精によるDROPである。

# 10. 第3校の文体制御

第3校では、第一校の反省として、以下を守る。

## 田中を派手にしすぎない

毎章、涙・絶叫・限界寸前を繰り返さない。
田中の反応は地味に深く、内側へ蓄積する。

## 同じ文型を繰り返さない

毎章以下の流れを丸ごと繰り返さない。

* 田中が赤くなる
* 観客が沸く
* 冬木が効いていると読む
* 狩野が俺を見ていないと思う
* 田中が「次は何をすればいいですか」と言う

章ごとに見せる役割を変える。

* 初期拡張：停止後の戻り
* 保持：姿勢を保つ身体
* 器具：見られる羞恥
* 段階式拡張：申告の上手さ
* 奉仕：安全行動としての奉仕
* 初回挿入：狩野を受けても狩野を見ない
* 反復挿入：待つのではなく備えている
* 自己申告：「俺が引き受けます」の誤読
* 総仕上げ：冬木の完成確信
* TRY：反応と完成の差

## 冬木を下品にしない

冬木の支配は、派手な罵倒ではなく、配置、手順、反復、停止位置、自己申告のタイミングに現れる。

## 狩野に答えを言わせすぎない

狩野の違和感は、第二部では断片でよい。
「俺を見ていない」「終わると消える」「待っているんじゃない」程度で止める。

## 露骨すぎる比喩を避ける

以下のような表現は避ける。

* 内臓まで見える
* 太い脳髄
* 獣が捕食される姿勢
* 俺だけの色に染める
* precum など英文混じり

文体は、過剰に猥雑にせず、制度・観察・身体反応の描写を中心にする。
