
# 世界観の基本

舞台は、CCI（Civic Credibility Index）によって市民の価値が管理される信用スコア社会である。

CCIは就労、住居、通信、医療、社会復帰資格に直結する。
CCIを失った者は、一般社会でまともに生活できなくなる。

低CCI者には、再統合施設、信用回復労働、公開競技、地下施設送りなどの救済・処理ルートが用意されている。
ただし、それらは本質的には救済ではなく、羞恥、労働、奉仕、見世物化を通じて社会の底へ循環させる制度である。

本作の中心にあるのは、公開競技型の再統合特例「KING-LAST」である。

---

# KING-LASTの基本

KING-LASTは、社会復帰不能域に落ちた成人男性が、最後のCCI回復権を賭けて参加する公開競技である。

参加者は全員成人男性。

競技は、KINGとSLAVEに分かれて進行する。
KINGはカードを選び、主対象と補助役を指定し、SLAVEへ命令を行う。
SLAVEは命令され、見られ、奉仕し、受容し、身体と羞恥の履歴を刻まれる。

KINGは毎ターン交代しない。
一度KINGになった者は、失脚するまで王権を保持する。

王権喪失条件は以下。

- CUMSHOT TRYに失敗する
- 王権ゲージが0になる
- KING自身が射精してDROPする
- 運営が競技不能と判定する

KINGを失脚させた者はCROWN BREAKERとなり、次代KINGになる。
失脚したKINGはDEBTとなり、自分が在任中に行った命令履歴を正順で返される。
これをミラー・カスケードと呼ぶ。

射精した参加者は、通常カード中、TRY中、ミラー中を問わず即時DROPとなる。
DROPした者は競技から退場し、CCH-LIVESTOCK-01へ送致される。

---

# CCH-LIVESTOCK-01

CCH-LIVESTOCK-01、通称「躯畜房」は、敗者や低CCI者を収容・管理する地下施設である。

ここでは、身体反応、羞恥、奉仕、展示、排出、従属姿勢などが制度的に管理される。
人間は名前ではなく役割や番号で扱われ、労役・奉仕・展示・管理対象として再定義される。

KING-LASTの敗者は、DROP後にこの施設へ送られる。
第二部本文では、CCHの詳細描写は必要最小限でよい。
ただし、参加者にとってDROPは単なる敗北ではなく、CCH送りを意味する重大な転落である。

# 第二部開始時点

第一部で初代KINGの市川誉はDROPした。
市川は観客受けを優先し、反応を散らした結果、履歴を完成させられずに敗北した。

市川を破った冬木将人が二代目KINGとなる。

第二部の主な参加者は以下。

- 冬木将人：二代目KING
- 田中達也：SLAVE。第二部の主対象
- 狩野豪：SLAVE。冬木が固定する補助役・実行役

第二部の大枠は、冬木が田中を主対象にし、狩野を固定補助役として使う展開である。

冬木は第一部のログから、田中の尻への反応、受容姿勢、狩野が関わる時の身体の変化を拾う。
冬木は、田中を尻から崩す方針を立てる。

前半は、狩野の指や器具で田中の尻を段階的に開く。
後半は、狩野に田中を何度も犯させる。
最後にCUMSHOT TRYで田中をDROPさせようとする。

この作戦は合理的に見える。
田中の身体は実際に反応する。
恥じらいも出る。
狩野を受けると強く乱れる。

しかし、TRYでは田中は射精しない。
冬木は失脚し、田中がCROWN BREAKERになる。
その後、冬木には自分が田中へ行った履歴が正順で返される。

# 第二部の章の流れ

1. 冬木が二代目KINGとなる。市川の失敗を「反応と完成の混同」と見る。田中を主対象、狩野を固定補助役にする。
2. 狩野の指による初期拡張。田中の羞恥と身体反応を濃く描く。
3. 指の本数と保持時間を増やす。田中の耐える身体、狩野の手の重さ、観客の視線を書く。
4. 小型器具による保持拡張。開かれたまま晒される羞恥を書く。
5. 段階式器具による拡張。声、汗、呼吸、腰の逃げ、耐える言葉を書く。
6. 拡張状態で狩野へ奉仕させる。屈辱と奉仕の熱を書く。
7. 狩野による初回挿入。田中が狩野を身体で受ける章。
8. 狩野による反復挿入。停止と再開、待たされる身体、狩野の体温を書く。
9. 犯されながら自己申告させる。「できます」「続けます」「俺が引き受けます」を使う。
10. TRY前総仕上げ。前半・後半の履歴を濃く重ねる。
11. CUMSHOT TRY。冬木が積んだ履歴を一気に重ねる。田中の身体は限界まで反応するが、射精しない。
12. 冬木への拡張ミラー。田中には耐える命令だったものが、冬木には屈辱と快感として返る。
13. 冬木への奉仕ミラー。狩野と冬木の距離を田中が見せつけられる。
14. 冬木への挿入ミラー。狩野が冬木を犯す光景を田中が見て、身体が疼く。
15. 総仕上げミラー。冬木が自分で作った履歴に追い込まれる。
16. 田中の追撃カード。田中が冬木へ口唇奉仕・尻奉仕を行い、冬木はTRY前に射精してDROPする。

第二部の終点は、冬木DROPだけではない。
田中が初めて「混ざりたい」という未整理な欲望に触れ、狩野が田中への執着を深めた状態で第三部へ渡す。

# 本文生成の優先方針

第二部は官能小説として書く。
設定説明や心理注釈を優先しすぎない。

制度やルールは、表示、命令、観客の反応、身体の変化で見せる。
本文中で「これは処理である」「これは誤読である」と説明しすぎない。

まず身体を書く。

- 田中の尻
- 呼吸
- 汗
- 声の漏れ
- 腰の逃げ
- 太腿の震え
- 狩野の手
- 狩野の体温
- 冬木の命令
- 観客の視線
- 止められた時の余韻

設定破綻やルールのズレは、後の修正で直せばよい。
初稿では官能の勢いを優先する。

# 田中達也の扱い

田中は無反応ではない。
恥ずかしい。身体は反応する。声も漏れる。汗も出る。腰も逃げる。尻も覚える。

ただし、田中は自分から「欲しい」とは言わない。
反応しても、以下の言葉で耐えようとする。

- 「大丈夫です」
- 「できます」
- 「まだ、できます」
- 「続けます」
- 「止めなくて、大丈夫です」
- 「俺がやります」
- 「俺が引き受けます」
- 「迷惑はかけません」

「次は何をすればいいですか」は多用しない。
重要な章末や転換点だけで使う。

田中は派手に叫び続けるタイプではない。
しかし、官能描写を薄くしない。
声を殺す、喉で詰まる、息が漏れる、身体が震える、尻が反応する、腰が逃げる、汗が落ちるなどで濃く書く。

# 冬木将人の扱い

冬木は第二部のKING。
静かで、観察型で、手順を組む。
市川のように観客へ叫ばない。

ただし、無味な解説者にしない。
冬木は田中の身体を見て、命令を重ね、言葉で逃げ道を潰す調教師である。

冬木の命令は短く、具体的にする。

- 「続けろ」
- 「止めるな」
- 「今の声を覚えておけ」
- 「誰に開かれているか言え」
- 「受けられるなら、そう言え」
- 「狩野を待て」
- 「そこで止めろ」
- 「もう一度だ」

冬木の説明は少なくてよい。
命令と観察で支配する。

---

# 狩野豪の扱い

狩野は第二部で冬木の固定補助役・実行役になる。
田中の尻を開き、器具を扱い、後半では田中を犯す。

狩野を単なる道具にしない。
狩野は体温、手、声、重さ、息を持った相手として書く。

田中の身体には狩野の手応えが残る。
狩野の側にも、田中の反応が残る。

狩野はまだ田中を救わない。
答えを早く言わない。
ただ、田中が強く反応するのに自分を求めきらないことへ、言葉にならない棘を覚える。

# 禁止事項

以下を本文で多用しない。

- これは処理である
- これは欲望ではない
- 冬木は誤読している
- 狩野は履歴条件である
- システム判定が進行している
- 外部入力に対する出力
- 業務用反応
- 商品化された恥じらい

必要な意味は、身体描写と台詞で出す。

説明ではなく、場面で書く。
