# 第一章　参加番号06

窓のない車内は、ひんやりとした空気とタイヤがアスファルトを削る低い音だけが満ちていた。地下へと沈んでいく感覚。喉の奥に重苦しい塊が詰まったようで、田中達也は奥歯を噛み締めた。

CCIが80を切れば、もう人間としての体裁すら保てない。KING-LASTは、そんな落ちぶれた者たちに与えられた最後の賭けだった。生き残れば再起のCCIを得られるかもしれない。だが負ければ----『躯畜房』へ堕ちる。名前を失い、番号と属性で管理される家畜としての余生が待っている。

車両が停止し、無機質な誘導に従って降り立ったのは、地下の冷たいコンクリートの通路だった。

「私物をすべて回収します」

係員に告げられ、達也は上着を脱ぎ、ボタンを外し、下着までも足元へ落とした。最後の日常の残滓が剥ぎ取られていく。裸になった自分の体は、長年の夜勤労働で脂肪と筋肉が層をなした無骨な塊だ。それを無遠慮な視線が舐め回す。

手渡されたのは競技衣装と呼ばれる布切れだった。

白いストレッチ素材のタンクトップは、肌に張り付くように密着した。110キロの肉付きを隠す気など毛頭なく、むしろ強調するかのように胸板の厚みや腹の膨らみを浮き彫りにする。布地は薄く、乳首の形や色まで透かしそうだ。少しでも動けば、擦れる感触が直接突先を刺激しそうで背筋がゾクゾクする。

黒い光沢素材のショートボクサーパンツは、太い腿の付け根と尻たぶを包み込みながらも、股間の膨らみを露骨に押し上げていた。股布が食い込み、先端が擦れるたびに下肢に甘い痺れが走る。

最後に首へ巻かれた黒い革製首輪。冷たい金具が喉仏を圧迫する。リストには同じく黒いバンド。

これが「商品」としての出陣姿か。鏡に映った自分は、もはや物流倉庫で荷を運ぶ男ではなかった。見世物小屋に放り込まれた、肉付きの良い家畜だ。

準備室へ通されると、すでに三人の男がいた。

「よう、お前もか」

真っ先に声をかけてきたのは、根元の黒い金髪に安っぽいタトゥーが目立つ男だった。市川誉。30歳にしては脂っこい笑顔を貼り付けている。

「その体、結構イケるじゃん。無骨系ってやつ？ こういうの、配信でウケるんだよね」

市川の視線は達也の人間性ではなく、画面映えする肉体に注がれていた。まるで商品棚から食材を選ぶような軽薄さ。

「……田中です」

「俺は市川。イチカワでいいよ。あっちのがフユキで、こっちのがカノウ」

市川が顎で示した先にいたのは、静かに達也を見つめる男だった。均整の取れた筋肉質な体躯に濃い胸毛が透けるタンクトップは、彼を「仕上げられた素材」のように見せた。冬木は何も言わず、ただ達也の厚い腹や太い腕を品定めするように観察している。その静かな眼差しには、品定め以上の何か、底知れない圧力があった。

もう一人は部屋の隅にいた。広い肩幅と潰れた耳が物語る格闘技崩れ。狩野は誰とも目を合わせず、部屋の隅々まで視線を走らせていた。カメラの位置、観客席への出口、運営の動線----自分たちが置かれた状況を冷徹に把握しようとしているのが分かった。

「さてと、そろそろ時間かな」

市川が軽く手を叩いた。

地下競技場へと引き出される。

観客席から降り注ぐ無数の視線と配信カメラの冷たい赤い光。達也は股間の黒い布地が視線にさらされると同時に、股布の中で自身が微かに震えるのを感じた。恥辱と恐怖が入り混じった痺れが下肢を突き抜ける。

運営によるアナウンスが響く。

『初代KING選出投票を行います』

観客席から低いざわめきと共に、何かが決まっていく気配。

「やっぱり俺だよな」

市川が口元を歪めて笑う。しかし瞳の奥には焦りのような揺らぎがあった。

『初代KING――市川誉に決定しました』

ブザー音と共に市川の首輪表示が『KING』へと切り替わる。

冬木は市川の笑顔の裏にある焦りを見透かすような冷ややかな目を向けた。
狩野は市川が王冠を受け取った瞬間、微かに重心を沈めた。警戒レベルが一段上がったのが分かった。

そして達也は----自分の首輪表示が『SLAVE』へと切り替わるのを見た。

冷たい文字が喉元で明滅する。

もう後戻りはできない。自分はこの檻の中で『使われる側』に落ちたのだ。
地下競技場の空気が重く沈み込む中で、達也は拳を握りしめた。

# 第二章　最初の王冠

地下競技場を覆う冷たい空気が、電子音と共に揺れた。壁面の巨大モニターに淡い光が灯り、無機質な文字が浮かび上がる。

『KING-LAST 競技規則』

達也は息を詰めて画面を見上げた。逃げ場のない檻の中で、これから自分たちが従わされるルールが提示されるのだ。

『1. KINGは1ターンに1枚、命令カードを選択する』
『2. ペアセッションの場合、KINGは主対象と補助役を指名する』
『3. 主対象は調教を受け、DROP条件へ近づく。補助役は主対象を仕上げるための奉仕・従属役割を担う』
『4. KINGは10ターン以内に特定のSLAVEを「完成」させなければならない』
『5. 第4ターン以降、任意でCUMSHOT TRYを発動可能』
『6. 第10ターンにおけるCUMSHOT TRYは強制である』
『7. CUMSHOT TRY成功＝対象DROP（CCH躯畜房へ移送）』
『8. CUMSHOT TRY失敗＝KING失脚。TRYを耐えたSLAVEはCROWN BREAKERとして次期KINGへ就任する』
『9. 失脚したKINGには「ミラー・カスケード」が執行される----』

最後の項目が表示された瞬間、達也は背筋に冷たいものが走るのを感じた。

『元KINGは在任中に命じたすべての命令履歴を、SLAVE側の立場で正順に返済する。役割、公開性、羞恥、相手関係も全て返される。なお返済は一段重く執行される（王権利息）』

自分が命じた行為を、今度は自分が受けさせられる。しかもより重く。それは単なる敗北以上の屈辱と恐怖を約束するものだった。画面の横には『CCH-LIVESTOCK-01 躯畜房』の文字と共に、番号で呼ばれる男たちの映像が小さく流れた。名前を失い、ただの肉の道具として扱われる未来。それはCCIの数字が消えること以上に、人間としての尊厳を根こそぎ奪う地獄だった。

「へぇ、結構ハードなんだな」

市川が気安い口調で呟いた。その声には緊張よりも、「自分には関係ない」という安堵が混じっているように聞こえた。

「でも要は観客にウケりゃいいんでしょ？ 盛り上げて、盛り上げて……最後は一番弱そうな奴を選べば勝てるってことじゃん」

市川はミラー・カスケードの恐怖を理解していない。いや、理解したくないのだろう。彼にとってこのゲームは配信企画の延長線上にある。三人を上手く回して面白い絵を作れば勝てると信じている。

対照的に、冬木はルールを見つめたまま動かなかった。その険しい横顔には感情を読み取れない。

狩野は腕組みをしたまま、冷ややかな目でモニターを見ている。このゲームの残酷さを、彼は肉感的に理解しているようだった。

『第1ターン開始』

アナウンスと共に市川の前にカードが提示される。市川は軽い足取りでそれを手に取った。

「よし、まずは……これだな」

市川が選んだのは『公開・命令復唱』。ソロセッション。

「主対象……冬木」

市川が冬木を指差す。無表情な筋肉ダルマをどうにかしてやりたいという安っぽい見世物根性だ。

「補助役はなしね。俺とお前の1対1だ」

冬木は無言で市川の前に進み出た。黒い首輪が喉元で鈍く光る。

「いいか、お前は俺のSLAVEだ。観客のみんなに向かって、自分の名前と立場を言え」

市川がカメラに向かってニヤリと笑い、冬木に命じる。

冬木はゆっくりと観客席へ顔を向けた。

「……冬木将人。KINGのSLAVEです」

声は低く平坦だった。だがその時、達也は見てしまった。冬木の喉仏が上下し、タンクトップの下で分厚い胸筋がキュッと収縮するのを。白い布地に浮かび上がる乳首の突起が、微かに硬くなった気がした。

「もっとハッキリ言えよ！ お前、俺に支配されてどう思ってんだよ？」

市川が踏み込む。冬木の眉がピクリと動き、唇がわずかに震えた。

「……支配されています。KINGに、使われています」

その言葉には屈辱よりも、何か粘着質なものが張り付いていた。市川はそれを見て、「隠してた本音が出た」と勝手に解釈したのか満足げに笑った。

「だろ？ 素直になればいいんだよ」

だが観客席からの反応は鈍い。「それで？」「次は？」という冷ややかな空気が伝わってくる。反応を見つけたことと、それを完成へ導くことは別だ。市川には次の手がない。

『第1ターン終了』

観客投票による判定が表示される。

『KING LOSE』

ブザー音と共に市川の王権ゲージが3から2へ減った。

「はあ？ 何でダメなわけ？」

市川がカメラに向かって不満顔を作る。「反応出たじゃん。あいつビビってたよ？ 観客の趣味悪くね？」

市川は自分の判断を正しいと思いたい。そしてその責任を観客へ押し付けようとする。
冬木は静かに元の位置へ戻った。その横顔には何の表情もない。しかし達也には分かった。冬木は市川を見限っている。
次は自分かもしれない。その予感に、達也は股間の黒い布地の中で自身が微かに震えるのを感じていた。 

# 第三章　三人の反応

『第2ターン開始』

電子音が響き、市川の前に新しいカードが提示される。市川はニヤリと笑い、「奉仕・姿勢固定ペア」を選んだ。

「主対象……田中。補助役は冬木」

達也は息を呑んだ。自分が主対象。しかも冬木から奉仕を受ける側だ。

「冬木、こいつを気持ちよくさせろ。四つん這いにして、隅々まで触ってやれよ」

市川の軽薄な命令に、冬木は無言で達也の背後に回った。達也は言われるままに床へ手をつく。硬い床に膝と掌が触れ、黒いショートボクサーパンツが太い腿に食い込む感触が鮮明になる。

「……失礼します」

冬木の低い声と共に、分厚い胸板が達也の背中に押し付けられた。熱と重み。そして冬木の太い腕が、達也の脇腹から腹へと這い上がる。

「っ……」

達也は声を漏らしそうになり、唇を噛んだ。他者の体温と感触に、体が強張る。拒否したい。でも拒めば場が荒れる。冬木の手がタンクトップの下へ滑り込み、荒れた肌を直接撫で上げると、達也の筋肉がビクビクと波打った。

冬木の指先が達也の乳首の周囲をなぞる。直接触れてはいないのに、その気配だけで乳首が硬く尖り、布地を押し上げた。

「ほら、もっと声出せよ。気持ちいいんだろ？」

市川がカメラに向かって笑う。達也は恥ずかしさに腰を引いたが、その動作がかえって冬木の太腿に自身の尻を擦り付ける形になり、黒い布地の中で男性的なものが微かに膨らむのを感じた。耐えようとするほど、内側に感覚が溜まっていく。

だが市川の視線は達也の反応には向いていなかった。「筋肉質な冬木が巨体のおっさんを扱うとか、結構いい絵じゃん」と自分の演出に酔っている。

「おっ、いい感じじゃん。冬木、もっと攻めて」

冬木は淡々と手を動かしながら、市川の言葉など耳に入っていないかのような静けさだ。だがその指先は確実に達也の反応の核を探り当てていた。

『第2ターン終了』

『KING WIN』

ブザー音と共にゲージが2から3へ戻る。

「やっぱり回せば当たるんだよ」と市川は得意げだ。達也は床から起き上がりながら、自分の中に残ったモヤモヤとした感覚と、それを見ていない市川への空虚さに唇を噛んだ。

『第3ターン開始』

市川は次のカードを選ぶ。「胸部・公開」。

「主対象……狩野」

狩野の眉がピクリと動く。

「お前らこいつの乳首いじってやれよ。強面だけど感じるんじゃね？」

観客席への媚びた言葉に、狩野の目が鋭く光る。だが拒否権はない。

「自分で弄れ」

市川は安全圏から命じた。狩野は舌打ちし、タンクトップを捲し上げた。露わになったのは、傷跡のような筋と共に盛り上がった厚い胸板と、濃い胸毛。そしてその中心で主張する二つの突起。

太い指が乳首を摘み上げる。

「…………っ」

屈辱と刺激に、狩野の顔が歪む。強がってカメラを睨みつけているのに、指先は容赦なく乳首を捏ねり回し、身体は正直に反応してしまう。尖った乳首は充血し、股間ではショートボクサーパンツが不本意な膨らみを主張し始める。

「あはは、すげー反応。マジで感じてんじゃん」

市川は面白がるが、狩野の殺気立った視線に当てられ、「でも怖い怖い」と近づこうとしない。

『第3ターン終了』

『KING LOSE』

ゲージは3から2へ下がる。

「何だよあいつマジで怖いし」と市川は不満げだ。狩野はタンクトップを下ろし、荒い息を吐きながら席へ戻った。その目には「怖いなら近づくな」という軽蔑が浮かんでいた。

『第4ターン開始』

市川は焦り始めていた。「奉仕・公開評価ペア」を選ぶ。

「主対象……冬木。補助役は田中」

また冬木だ。

「田中、お前が今度は奉仕する側だ。冬木を気持ちよくさせろ」

達也は冬木の前に跪いた。ぎこちなくタンクトップ越しに冬木の胸板へ手を添える。筋肉の硬さと熱が伝わる。

冬木は無表情だが、達也の手が動くたびに微かに呼吸が乱れるのが分かった。達也の大きな手が胸元へ掛かると、冬木の乳首が皮一枚を押し上げて硬直した。

「どうだ冬木？ 隠せないだろ？」

市川は冬木の反応だけを見る。しかし第1ターンの「命令復唱」とは全く異なる条件だ。他人からの奉仕による反応。履歴として繋がっていない。

達也は相手を満たそうと真面目に触れるあまり、無意識に冬木の性感帯を刺激してしまう。冬木の喉仏が上下し、タンクトップの下で腹筋が痙攣した。

『第4ターン終了』

『KING LOSE』

ゲージは2から1へ下がる。

「あいつら使いにくいなぁ……」

市川は不満げだ。しかし冬木には見えていた。市川が三人の反応を「見世物」として消費しているだけで、「履歴」として積み重ねていないことを。これでは最後のTRYで賭ける相手もいない。
達也は自分の手についた冬木の体温を感じながら、「使われ方」に利用されたことに言葉にできない空虚さを覚えていた。

# 第四章　浅い開発

『第5ターン開始』

残りターンの減少と、行き来するゲージに市川の焦りが滲み始める。彼は新たなカード「後背・受容姿勢ペア」を選び、舌なめずりをした。

「主対象……田中。補助役は狩野」

達也の眉が曇る。また自分が主対象だ。しかも補助役は、あの殺気立った格闘家だ。

「おいデカいの、こいつの後ろから触ってやれよ。責任者っぽくよ」

市川の安直な指示に、狩野は不機嫌そうに鼻を鳴らしたが、従わない選択肢はない。達也は再び床へ手をつき、四つん這いの姿勢を取らされる。黒いショートボクサーパンツが太い臀肉に食い込み、無防備な後背が晒される。

狩野の分厚く、傷だらけの手が達也の背中に触れた。

「っ……！」

力が強い。マッサージというより、相手をねじ伏せるような圧力だ。太い指が脊柱の両側を南南東に這い、腰骨を掴むように捏ね上げる。達也の筋肉がその圧に耐えきれず、ビクビクと波打った。

「自分で腰振ってみろ。気持ちいいだろ？」

市川が煽る。達也は屈辱に唇を噦みながら、狩野の手のひらに自身の臀部を押し付けるように腰を動かした。ズリ、と布が擦れる卑猥な音が響く。

狩野の手が臀肉を鷲掴みにする。荒い手つきに、達也の肉が卑猥に揺さぶられる。耐えようと息を殺すほど、内側に感覚がどす黒く溜まっていく。ショートボクサーパンツの中で男性的なものが太く脈打ち、先走りが滲むのが分かった。

「もっと声出せよ、つまんねーな」

市川は不満げだ。達也の抑圧された喘ぎも、震える筋肉も、彼には「地味」に見える。だが観客席には、達也が必死に耐えることでかえって濃厚なエロティシズムを放っているのが見えていた。狩野の圧倒的な存在感と、達也の従順さのコントラスト。

『第5ターン終了』

『KING WIN』

ブザー音と共にゲージが1から2へ戻る。

「やっぱ絵面だよな」と市川は独り言ち、達也の反応の核には目もくれない。

『第6ターン開始』

市川は再び狩野に狙いを定めた。「胸部・命令復唱」を選ぶ。

「主対象……狩野」

狩野の顔に苛立ちが浮かぶ。

「ほら、自分で乳首弄って声出せよ」

市川は安全圏から命じる。狩野は舌打ちし、タンクトップを捲し上げた。前回の履歴が残り、濃い胸毛に囲まれた乳首はすぐに硬く尖る。

太い指が乳首を摘み、引っ張る。

「……っ、く」

屈辱と刺激に、狩野の顔が歪む。

「気持ちいいって言え」

「……気持ち、いい……っ」

憎々しげに市川を睨みつけながら、屈辱的に復唱する。強がっているのに、声は微かに震え、股間では再びショートボクサーパンツが不本意な膨らみを主張し始める。命令を受けているという状況そのものが、彼の強がりを内側から崩し始めていた。

「おっ、いけるか？」

市川は期待に目を輝かせる。だが、狩野の殺気に満ちた視線が突き刺さり、近づいてさらに追い詰める勇気は出なかった。「ま、まあいいや」と一歩退く。
